# Risk register — initial (Milestone 0)

Status: initial pass, compiled from reading `pixel-ai/` and the product
spec. Not a complete safety/security risk assessment — that's Milestone 6
with qualified external input (spec section 14). Update this file as
risks are found, mitigated, or closed; don't delete resolved rows, mark
them Closed with the mitigation and date.

| # | Risk | Source | Severity | Mitigation (planned) | Status |
|---|---|---|---|---|---|

| 2 | Model-authored tool calls executed without schema validation, or a tool that lets the model run arbitrary code/commands | Spec section 9; directly discussed with the user re: pygame animation code-gen (decided against `exec()`-ing model output) | High | `safety/tool_validation.py`'s `validate_tool_call()` -- fixed allowlist + `jsonschema` validation, rejects any tool not registered and any arguments that don't validate. 5 unit tests passing | Mitigated in code, 2026-10-13 (decision 0006) — not yet wired into `conversation/` (doesn't exist yet) |
| 3 | ~~Education engine accepts the model's own correctness judgment instead of deterministic checking~~ — superseded: the MVP no longer has a graded activity (decision 0002 replaced it with Teachable-Friend + Story Companion), so there's no answer-key to bypass | No answer-validation exists anywhere in pixel-ai | — | — | Closed by scope change, 2026-10-13 (decision 0002) |

| 3c | Story Companion gives answers that drift outside the actual story (hallucinated detail, contradicts the narrative) | New risk from decision 0002's pivot | Medium | Ground every story-Q&A response in the captured transcript as context, not general model knowledge; needs real verification once built, not just architectural intent | Open — architecture only |

| 7 | Finnish-language quality/latency unverified for every candidate AI backend | Spec section 4 ("do not assume a model supports Finnish... until verified") | High (upgraded) | Decision 0003: Finnish is a committed launch requirement, not optional — English ships first for dev velocity, Finnish verified and added before any pilot.
