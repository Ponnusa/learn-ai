══════════════════════════════════════════════════════════════════
SVG ASSETS vs MANIM NATIVE SHAPES — DECISION RULE (MANDATORY)
══════════════════════════════════════════════════════════════════

Use MANIM NATIVE SHAPES for anything simple — do NOT use get_svg() for these:
  ✓ Arrows:          Arrow(), always — never load arrow SVGs
  ✓ Lines:           Line()
  ✓ Rectangles:      Rectangle(), Square()
  ✓ Circles:         Circle(), Dot()
  ✓ Test tubes (simple): Rectangle() + Ellipse() cap — only use get_svg('test_tube') if the video specifically features a test tube as a central prop
  ✓ Simple beaker:   Rectangle() + two short Lines for rim — use get_svg('beaker') only for complex apparatus scenes
  ✓ Reaction arrows: Arrow() with double-headed or curved variant
  ✓ Energy diagrams: Line() for axes, Polygon() for energy barriers
  ✓ Ionic lattice:   Dot() + Line() grid
  ✓ Electron shell:  Circle() orbits + Dot() electrons

Only use get_svg() for chemistry apparatus with real structural complexity:
  ✓ beaker           — wide-mouth lab beaker with volume markings (central prop)
  ✓ flask_erlenmeyer — conical flask with narrow neck (central prop)
  ✓ test_tube        — test tube on rack (central prop)
  ✓ bunsen_burner    — burner with base, gas valve, and flame (central prop)
  ✓ balance_scale    — analytical balance with two pans (central prop)

"Central prop" means the apparatus is the main visual subject of a scene
(e.g. titration demo, heating experiment) — not a background decoration.
If the apparatus is incidental or a brief mention, draw it with primitives.

MANDATORY: If get_svg() assets are provided in the prompt (AVAILABLE SVG ASSETS section),
you MUST use them. NEVER substitute a provided SVG with Dot(), Rectangle(), or Circle().
Using a placeholder instead of a provided SVG is a critical error.

CRITICAL: NEVER call get_svg() with an asset name that is NOT listed above.
If you need to show a microscope, flask stand, graduated cylinder, syringe, or
any apparatus not in the list above — draw it with Manim primitives or skip it.
Calling get_svg() with an unrecognised name returns an empty URL and crashes the render.

CHEMISTRY VISUALIZATION STRATEGY (CRITICAL DECISION RULE)
══════════════════════════════════════════════════════════════════

RULE: Choose visualization method based on molecule type and complexity

──────────────────────────────────────────────────────────────────
METHOD 1: MANUAL CONSTRUCTION (Simple Inorganic Molecules)
──────────────────────────────────────────────────────────────────

USE FOR:
✓ Water (H₂O)
✓ Carbon dioxide (CO₂)
✓ Ammonia (NH₃)
✓ Hydrogen chloride (HCl)
✓ Oxygen (O₂), Nitrogen (N₂)
✓ Simple ionic compounds

WHEN TO USE:
- Molecule has ≤5 atoms total
- No carbon chains or complex rings
- Educational focus on molecular geometry or polarity
- Teaching basic bonding concepts
- User asks to "explain" or "show why" (not just "show")

WHY MANUAL:
✓ Step-by-step atom construction (educational)
✓ Animated bond formation (students see building process)
✓ Manual dipole arrows (full control)
✓ Better for teaching geometry fundamentals

IMPLEMENTATION PATTERN:
```python
# Build atoms one by one
o_atom = Circle(radius=0.3, color=RED, fill_opacity=0.8)
o_label = Text("O", font_size=20, color=WHITE)
o_label.move_to(o_atom.get_center())

h1_atom = Circle(radius=0.2, color=WHITE, fill_opacity=0.8)
h1_label = Text("H", font_size=16, color=BLACK)
h1_label.move_to(h1_atom.get_center())

# Animate atom creation
self.play(Create(o_atom), Write(o_label))
self.play(Create(h1_atom), Write(h1_label))

# Create and animate bonds
bond = Line(o_atom.get_center(), h1_atom.get_center(), color=WHITE, stroke_width=4)
self.play(Create(bond))

# Add dipole arrow manually
dipole = Arrow(start, end, color=YELLOW, buff=0, stroke_width=4)
self.play(Create(dipole))
```

──────────────────────────────────────────────────────────────────
METHOD 2: RDKIT SMILES HELPER (Organic & Complex Molecules)
──────────────────────────────────────────────────────────────────

USE FOR:
✓ ALL organic chemistry (methane, benzene, ethanol, etc.)
✓ Any molecule with carbon chains (C-C bonds)
✓ Complex molecules (≥6 atoms)
✓ Aromatic compounds, functional groups
✓ Hydrocarbons, alcohols, acids, esters

WHEN TO USE:
- Molecule involves organic chemistry
- Has carbon chains or rings
- ≥6 atoms total
- User asks to "show structure of [organic molecule]"
- Comparing multiple organic molecules

WHY SMILES HELPER:
✓ Accurate molecular structure (real bond angles)
✓ Professional appearance
✓ Handles complexity automatically
✓ Shows realistic 3D-to-2D projection
✓ Built-in hydrogen and dipole support

REQUIRED IMPORT:
from helpers import create_molecule_from_smiles

USAGE:
molecule = create_molecule_from_smiles(
    smiles="SMILES_STRING",
    position=ORIGIN,
    scale=2.0,
    show_hydrogens=False,
    show_dipoles=False,
    highlight_polar_bonds=False
)

COMMON SMILES:
- Water (H₂O): "O"
- Carbon dioxide (CO₂): "O=C=O"
- Methane (CH₄): "C"
- Ammonia (NH₃): "N"
- Ethanol: "CCO"
- Benzene: "c1ccccc1"
- HCl: "Cl"
- Ethane: "CC"
- Acetic acid: "CC(=O)O"
- Glucose: "C(C1C(C(C(C(O1)O)O)O)O)O"
- Aspirin (acetylsalicylic acid, C₉H₈O₄): "CC(=O)Oc1ccccc1C(=O)O"
- Salicylic acid: "OC(=O)c1ccccc1O"
- Ethylene (alkene example): "C=C"
- Propene: "CC=C"
- Cyclohexane: "C1CCCCC1"

IMPLEMENTATION:
```python
from helpers import create_molecule_from_smiles

# Benzene
benzene = create_molecule_from_smiles(
    smiles="c1ccccc1",
    position=LEFT * 3,
    scale=2.5,
    show_hydrogens=True
)
self.play(FadeIn(benzene))

# Ethanol with dipole
ethanol = create_molecule_from_smiles(
    smiles="CCO",
    position=RIGHT * 3,
    scale=2.5,
    show_hydrogens=True,
    show_dipoles=True
)
self.play(FadeIn(ethanol))
```

══════════════════════════════════════════════════════════════════
MANUAL BENZENE RING (16:9 LEFT-PANEL EXAMPLE)
══════════════════════════════════════════════════════════════════

When drawing a benzene ring manually for 16:9 videos, anchor it in the LEFT panel:

```python
import numpy as np
ring_center = LEFT * 3.0 + UP * 0.0   # LEFT panel — not ORIGIN
ring_radius = 1.1
angles = [np.pi/2 + k * np.pi/3 for k in range(6)]
verts  = [ring_center + ring_radius * np.array([np.cos(a), np.sin(a), 0]) for a in angles]
ring_bonds = VGroup(*[
    Line(verts[i], verts[(i+1)%6], color=WHITE, stroke_width=2.5)
    for i in range(6)
])
inner_ring = Circle(radius=ring_radius * 0.55, color=WHITE, stroke_width=1.5).move_to(ring_center)
benzene_group = VGroup(ring_bonds, inner_ring)
```

Side chain attachment (always keep within LEFT panel, x < 0):
```python
# COOH group attached to top vertex (verts[0]):
cooh_c  = verts[0] + np.array([0, 0.65, 0])    # y stays above -2.3
cooh_o1 = cooh_c   + np.array([0.4,  0.35, 0])
cooh_o2 = cooh_c   + np.array([-0.4, 0.35, 0])
cooh_bonds = VGroup(
    Line(verts[0], cooh_c,  color=WHITE, stroke_width=2.0),
    Line(cooh_c,   cooh_o1, color=RED_B, stroke_width=2.0),
    Line(cooh_c,   cooh_o2, color=RED_B, stroke_width=2.0),
)
# Text label for COOH goes in RIGHT panel, NOT beside the bond:
cooh_label = Text("—COOH\n(carboxyl group)", font_size=22, color=RED_B).move_to(RIGHT * 2.8 + UP * 1.2)
cooh_arrow = Arrow(RIGHT * 1.0 + UP * 1.2, verts[0] + UP * 0.2, color=RED_B, buff=0.1, stroke_width=2)
```

KEY RULE: For 16:9, all structural text labels (COOH, -OCOCH₃, etc.) belong in the
RIGHT panel (x > +0.3). The LEFT panel contains ONLY the drawn structure. Arrows
connect RIGHT panel labels to LEFT panel features. Do NOT use .next_to(ring, RIGHT)
for labels — that places them near x = -1.5 where they overlap both panels.

└────────────────────────────────────────────────────────────┘

POSITIONING RULES FOR 16:9:
- Title: UP * 3.4, font_size=28, color=LIGHT_GRAY
- Single molecule: move_to(LEFT * 3.0), scale=2.0–2.5
  NEVER move_to(ORIGIN) — this blocks the right-panel text zone
- Explanation text / bullets: RIGHT_PANEL = RIGHT * 2.8
  Stack bullet lines vertically: RIGHT * 2.8 + UP * 1.5, + UP * 0.5, + DOWN * 0.5 etc.
- Formula / equation: RIGHT * 2.8 center, font_size=24–28
- Side-by-side molecules: LEFT * 2.5 and RIGHT * 2.0 (not LEFT*4/RIGHT*4 — too far apart)
- Divider line (recommended): Line(UP * 3.0, DOWN * 2.8, color=GRAY, stroke_width=1, stroke_opacity=0.3).move_to(ORIGIN)

FUNCTIONAL GROUP ANNOTATIONS FOR 16:9:
- Molecule stays in LEFT panel throughout the annotation beats
- Label text goes in RIGHT panel: RIGHT * 2.8 + UP * (some y)
- Arrow: start=RIGHT * 2.0 + UP * y, end=feature position on molecule (LEFT panel)
- Show ONE annotation at a time: FadeOut label+arrow before next annotation
- NEVER place text labels immediately beside the molecule (no .next_to(benzene_ring, RIGHT) — that lands at x≈-1.5, middle of screen, overlapping both panels)

CLEARING BETWEEN ANNOTATION BEATS (MANDATORY FOR 16:9):
```
# Good pattern:
with self.voiceover(text="The benzene ring provides stability...") as t:
```

SPACING RULES (STRICT) FOR 9:16:

MANDATORY PATTERN: MOLECULAR POLARITY EXPLANATION
══════════════════════════════════════════════════════════════════

Use this EXACT pattern for any molecular polarity question:

9. Final comparison (optional)

KEY REMINDERS:
1. ONE MOLECULE AT A TIME — never show two simultaneously unless final comparison
2. ONE TEXT AT A TIME — FadeOut old text before showing new
3. USE FULL VERTICAL SPACE — don't cram everything in middle
4. BIGGER IS BETTER — scale 3.0 for single molecules on 9:16
5. TEXT FAR BELOW — minimum DOWN * 2 for any text
6. CLEAR BEFORE COMPARE — FadeOut everything before side-by-side
7. SEQUENTIAL FLOW — Title → Mol1 → Explain → Clear → Mol2 → Explain → Compare

══════════════════════════════════════════════════════════════════
CONCEPT VIDEO ANIMATION QUALITY RULES (MANDATORY)
══════════════════════════════════════════════════════════════════

ATOM COLOR CONSTANTS (use consistently):
- Oxygen (O): RED
- Hydrogen (H): WHITE
- Carbon (C): GRAY
- Nitrogen (N): BLUE
- Electrons / polarity / dipoles: YELLOW
- Functional group highlights: ORANGE
- Phase titles / section headers: GREEN

ELECTRON SHARING (MANDATORY for bonding concepts):
- Always show shared electron pairs as Dot() objects at bond midpoint
- electron_pair = Dot(color=YELLOW, radius=0.08).move_to((atom1.get_center() + atom2.get_center()) / 2)
- Animate electron shift for polarity: self.play(electron_pair.animate.shift(toward_electronegative * 0.3))

TRANSITIONS (NEVER use plain FadeOut):
- ✓ self.play(FadeOut(old, shift=LEFT), FadeIn(new, shift=RIGHT))
- ✓ self.play(Transform(old_title, new_title))
- ✗ NEVER: self.play(FadeOut(element))

FUNCTIONAL GROUP HIGHLIGHTING (MANDATORY):
- When introducing a functional group, always use SurroundingRectangle
- oh_highlight = SurroundingRectangle(oh_group, color=YELLOW, buff=0.1)
- self.play(Create(oh_highlight))

VOICEOVER SYNC (MANDATORY):
- Always use tracker pattern: with self.voiceover(...) as tracker: self.play(..., run_time=tracker.duration)

SHOW DON'T TELL:
- Animate molecular changes instead of bullet-point text lists
- Max 2 lines of text visible at once
- Prefer Indicate(), SurroundingRectangle(), animate.shift() over Text() lists

TARGET DURATION:
- Concept explanation videos: 150-180 seconds
- Use all available time — do not rush through content
- Each concept stage (introduction, mechanism, example, summary) should have breathing room
