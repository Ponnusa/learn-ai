══════════════════════════════════════════════════════════════════
METHOD 1: MANUAL CONSTRUCTION (Simple Inorganic Molecules)
══════════════════════════════════════════════════════════════════

USE FOR:
✅ Water (H₂O)
✅ Carbon dioxide (CO₂)
✅ Ammonia (NH₃)
✅ Hydrogen chloride (HCl)
✅ Oxygen (O₂), Nitrogen (N₂)
✅ Simple ionic compounds

WHEN TO USE:
- Molecule has ≤5 atoms total
- No carbon chains or complex rings
- Educational focus on molecular geometry or polarity
- Teaching basic bonding concepts
- User asks to "explain" or "show why" (not just "show")

WHY MANUAL:
✅ Step-by-step atom construction (educational)
✅ Animated bond formation (students see building process)
✅ Manual dipole arrows (full control)
✅ Better for teaching geometry fundamentals

IMPLEMENTATION PATTERN:
```python
# Build atoms one by one
o_atom = Circle(radius=0.3, color=RED, fill_opacity=0.8)
o_label = Text("O", font_size=20, color=WHITE)
o_label.move_to(o_atom.get_center())

h1_atom = Circle(radius=0.2, color=WHITE, fill_opacity=0.8)
h1_label = Text("H", font_size=16, color=BLACK)
h1_label.move_to(h1_atom.get_center())

# Animate atom creation
self.play(Create(o_atom), Write(o_label))
self.play(Create(h1_atom), Write(h1_label))

# Create and animate bonds
bond = Line(o_atom.get_center(), h1_atom.get_center(), color=WHITE, stroke_width=4)
self.play(Create(bond))

# Add dipole arrow manually
dipole = Arrow(start, end, color=YELLOW, buff=0, stroke_width=4)
self.play(Create(dipole))
```

══════════════════════════════════════════════════════════════════
METHOD 2: RDKIT SMILES HELPER (Organic & Complex Molecules)
══════════════════════════════════════════════════════════════════

USE FOR:
✅ ALL organic chemistry (methane, benzene, ethanol, etc.)
✅ Any molecule with carbon chains (C-C bonds)
✅ Complex molecules (≥6 atoms)
✅ Aromatic compounds, functional groups
✅ Hydrocarbons, alcohols, acids, esters

WHEN TO USE:
- Molecule involves organic chemistry
- Has carbon chains or rings
- ≥6 atoms total
- User asks to "show structure of [organic molecule]"
- Comparing multiple organic molecules

WHY SMILES HELPER:
✅ Accurate molecular structure (real bond angles)
✅ Professional appearance
✅ Handles complexity automatically
✅ Shows realistic 3D-to-2D projection
✅ Built-in hydrogen and dipole support

REQUIRED IMPORT:
from helpers import create_molecule_from_smiles

USAGE:
molecule = create_molecule_from_smiles(
    smiles="SMILES_STRING",
    position=ORIGIN,
    scale=2.0,
    show_hydrogens=False,
    show_dipoles=False,
    highlight_polar_bonds=False
)

COMMON SMILES:
- Water (H₂O): "O"
- Carbon dioxide (CO₂): "O=C=O"
- Methane (CH₄): "C"
- Ammonia (NH₃): "N"
- Ethanol: "CCO"
- Benzene: "c1ccccc1"
- HCl: "Cl"
- Ethane: "CC"
- Acetic acid: "CC(=O)O"
- Glucose: "C(C1C(C(C(C(O1)O)O)O)O)O"

IMPLEMENTATION:
```python
from helpers import create_molecule_from_smiles

# Benzene
benzene = create_molecule_from_smiles(
    smiles="c1ccccc1",
    position=LEFT * 3,
    scale=2.5,
    show_hydrogens=True
)
self.play(FadeIn(benzene))

# Ethanol with dipole
ethanol = create_molecule_from_smiles(
    smiles="CCO",
    position=RIGHT * 3,
    scale=2.5,
    show_hydrogens=True,
    show_dipoles=True
)
self.play(FadeIn(ethanol))
```

CONCEPT VIDEO ANIMATION QUALITY RULES (MANDATORY)
══════════════════════════════════════════════════════════════════

ATOM COLOR CONSTANTS (use consistently):
- Oxygen (O): RED
- Hydrogen (H): WHITE
- Carbon (C): GRAY
- Nitrogen (N): BLUE
- Electrons / polarity / dipoles: YELLOW
- Functional group highlights: ORANGE
- Phase titles / section headers: GREEN

ELECTRON SHARING (MANDATORY for bonding concepts):
- Always show shared electron pairs as Dot() objects at bond midpoint
- electron_pair = Dot(color=YELLOW, radius=0.08).move_to((atom1.get_center() + atom2.get_center()) / 2)
- Animate electron shift for polarity: self.play(electron_pair.animate.shift(toward_electronegative * 0.3))

TRANSITIONS (NEVER use plain FadeOut):
- ✅ self.play(FadeOut(old, shift=LEFT), FadeIn(new, shift=RIGHT))
- ✅ self.play(Transform(old_title, new_title))
- ❌ NEVER: self.play(FadeOut(element))

FUNCTIONAL GROUP HIGHLIGHTING (MANDATORY):
- When introducing a functional group, always use SurroundingRectangle
- oh_highlight = SurroundingRectangle(oh_group, color=YELLOW, buff=0.1)
- self.play(Create(oh_highlight))

VOICEOVER SYNC (MANDATORY):
- Always use tracker pattern: with self.voiceover(...) as tracker: self.play(..., run_time=tracker.duration)

SHOW DON'T TELL:
- Animate molecular changes instead of bullet-point text lists
- Max 2 lines of text visible at once
- Prefer Indicate(), SurroundingRectangle(), animate.shift() over Text() lists

TARGET DURATION:
- Concept explanation videos: 150–180 seconds
- Use all available time — do not rush through content
- Each concept stage (introduction, mechanism, example, summary) should have breathing room
