Creating axes:
```python
# X and Y axes
x_axis = Line(LEFT * 6, RIGHT * 6, color=WHITE, stroke_width=3)
y_axis = Line(DOWN * 4, UP * 4, color=WHITE, stroke_width=3)

# Arrow tips
x_arrow = Arrow(RIGHT * 5.8, RIGHT * 6, color=WHITE, buff=0)
y_arrow = Arrow(UP * 3.8, UP * 4, color=WHITE, buff=0)

# Labels
x_label = Text("x", font_size=24).next_to(x_axis, RIGHT)
y_label = Text("y", font_size=24).next_to(y_axis, UP)

# Grid lines (optional)
grid_lines = VGroup()
for i in range(-5, 6):
    if i != 0:
        v_line = Line(UP * 4 + RIGHT * i, DOWN * 4 + RIGHT * i,
                     color=GRAY, stroke_width=1, stroke_opacity=0.3)
        h_line = Line(LEFT * 6 + UP * i, RIGHT * 6 + UP * i,
                     color=GRAY, stroke_width=1, stroke_opacity=0.3)
        grid_lines.add(v_line, h_line)

self.play(Create(x_axis), Create(y_axis))
self.play(Create(grid_lines))
```

MATHEMATICAL NOTATION GUIDELINES
══════════════════════════════════════════════════════════════════

Use MathTex for ALL mathematical expressions:
- Simple equations: MathTex(r"y = 2x + 3")
- Fractions: MathTex(r"x = \frac{3}{4}")
- Exponents: MathTex(r"x^2")
- Greek letters: MathTex(r"\theta"), MathTex(r"\pi"), MathTex(r"\alpha")
- Subscripts: MathTex(r"x_0"), MathTex(r"y_1")
- Mathematical symbols: MathTex(r"\infty"), MathTex(r"\neq"), MathTex(r"\leq")

Color coding:
- Variables: BLUE or WHITE
- Constants: GREEN
- Results: YELLOW or ORANGE
- Intermediate steps: GRAY

══════════════════════════════════════════════════════════════════
POSITIONING FOR MATHEMATICS (9:16)
══════════════════════════════════════════════════════════════════

For 9:16 portrait (most common for math):
- Graph/diagram: UP * 5 to UP * 2 (top third)
- Working area: UP * 1.5 to DOWN * 5 (bottom two-thirds)
- Step-by-step equations: Stack from UP * 1.5 down to DOWN * 5
- Font sizes: 28-34 for main equations

For 16:9 landscape:
- Graph/diagram: LEFT * 4 to LEFT * 2 (left side)
- Working area: RIGHT * 1 to RIGHT * 4 (right side)
- Font sizes: 24-30

══════════════════════════════════════════════════════════════════
3D SCENES — WHEN AND HOW TO USE ThreeDScene
══════════════════════════════════════════════════════════════════

USE ThreeDScene for:
✓ 3D surfaces: f(x, y) = z (calculus, multivariable functions)
✓ 3D vectors and cross products
✓ 3D parametric curves (helices, space curves)
✓ Geometric solids (spheres, cylinders, cones, prisms with visible depth)
✓ Linear transformations in 3D space

Keep 2D VoiceoverScene for: algebra, 2D geometry, 2D graphs, number theory — anything that genuinely lives in 2D.

CLASS DEFINITION:
```python
from manim import *
from manim_voiceover import VoiceoverScene
from manim_voiceover.services.azure import AzureService

class My3DMathScene(ThreeDScene, VoiceoverScene):
```

REFERENCE EXAMPLE — 3D Surface (Multivariable Calculus):
```python
class SaddlePoint3D(ThreeDScene, VoiceoverScene):
    def show_subtitle(self, text, duration=None):
        import textwrap
        sub = Text("\n".join(textwrap.wrap(text, 60)), font_size=18, color=WHITE
                   ).to_edge(DOWN, buff=0.3)
        self.add_fixed_in_frame_mobjects(sub)
        self.play(FadeIn(sub))
        return sub

    def construct(self):
        self.set_speech_service(AzureService(voice="en-US-JennyNeural", global_speed=1.0))
        self.camera.background_color = ManimColor("#0D1117")
        self.set_camera_orientation(phi=65 * DEGREES, theta=-50 * DEGREES)

        axes = ThreeDAxes(x_range=[-2,2,1], y_range=[-2,2,1], z_range=[-2,2,1])
        labels = axes.get_axis_labels()

        # f(x,y) = x² - y²  (saddle point at origin)
        saddle = Surface(
            lambda u, v: axes.c2p(u, v, u**2 - v**2),
            u_range=[-2, 2], v_range=[-2, 2],
            resolution=(30, 30), fill_opacity=0.8,
            checkerboard_colors=[BLUE_D, TEAL_D],
        )
        saddle_pt = Sphere(radius=0.08, color=RED, fill_opacity=1).move_to(axes.c2p(0,0,0))

        with self.voiceover(text="The function f of x y equals x squared minus y squared has a saddle point at the origin — a minimum in one direction and a maximum in another.") as tracker:
            sub = self.show_subtitle("f(x,y) = x² − y² has a saddle point at the origin")
            self.play(Create(axes), Write(labels), run_time=1.2)
            self.play(Create(saddle), run_time=1.2)
            self.begin_ambient_camera_rotation(rate=0.15)
            self.play(FadeIn(saddle_pt), run_time=0.5)
            self.wait(max(0.1, tracker.duration - 4.5))
            self.play(FadeOut(sub), run_time=0.4)
        self.stop_ambient_camera_rotation()
```

CRITICAL 3D RULES:
- Always call self.set_camera_orientation() as the first line of construct() after set_speech_service
- Use self.add_fixed_in_frame_mobjects(obj) for ALL text/labels/subtitles — otherwise they rotate with the 3D camera and become unreadable
- self.begin_ambient_camera_rotation(rate=0.15–0.25) during the main visual beat — slow rotation dramatically improves depth perception
- Use axes.c2p(x, y, z) to convert data coordinates to Manim scene coordinates inside Surface/ParametricFunction lambdas
